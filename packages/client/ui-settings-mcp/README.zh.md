# @deepseek-ai/dsh-client-ui-settings-mcp

[English](README.md) | 中文

MCP 设置页面插件。在设置页面注册 MCP 分区（位于 Models 页之后），用户在此配置 `mcp` 用户设置命名空间中的外部 MCP 服务器，并查看每个服务器的激活状态。

页面将两个 wire 域合并为一个快照：`settings.describe`（`mcp` 命名空间的解析值——已配置的服务器，已应用 schema 默认值）和 `mcp.list`（管理器按服务器的激活状态）。每个已配置的服务器渲染为一个卡片行，显示其名称、传输方式、启用状态和状态点（`已连接`、`连接中…` 或 `连接失败` 及失败文本）。编辑会展开该行的编辑器卡片；添加流程打开同一张空白卡片；删除需要确认对话框并指明服务器名称。

编辑器是覆盖两种传输方式的一张手写卡片：已有行的服务器名称字段锁定（重命名是原子的——一次 `settings.mutate` 同时 unset 旧键并 set 新键）、传输方式选择、stdio 字段（`command`、每行一个参数、每行 `KEY=VALUE` 环境变量、`cwd`）或 HTTP 字段（`url`、每行 `Key: Value` 请求头）、工具调用超时和启用开关。每次保存先做本地校验（服务器名称模式、必填传输字段、正数超时），再以 `settings.mutate` 路径操作落地，因此设置接缝自身的段校验是第二道关卡，被拒绝的写入会明确指出问题。页面从不重述未触碰的字段：只会 set 或 unset 被编辑服务器的键。

页面加载后会订阅转发的 `settings/document-updated` 事件和本地 `connection/reset`，因此外部 `settings.yaml` 编辑或第二个标签页的变更无需轮询即可收敛。

## 模型体验

无，该分区渲染的是浏览器配置界面；这里没有任何内容进入模型请求。

#### KV 缓存影响

无；本包既不组装也不发送任何提供商请求。

## 已知限制与待办

- **没有逐服务器暂停或测试按钮**——唯一的开关是启用切换（保留文档中的条目并断开连接），超出激活状态的连接健康状况留给管理器的日志。
- **不推送重连状态**——状态点反映的是上次页面加载；加载后掉线的服务器在下次刷新前仍显示`已连接`点，因为 `mcp/synced` 不会转发到浏览器。
- **请求头和环境变量是自由文本**——编辑器解析 `Key: Value` / `KEY=VALUE` 行；缺少分隔符的行会被静默跳过而非拒绝。
